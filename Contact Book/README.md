# Contact Book

## Project Description

This is a simple Contact Book application developed using Python. The program allows users to store and manage contact information, including name, phone number, email, and address. Users can add, view, search, update, and delete contacts through a menu-driven interface.

## Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Update contact information
- Delete contacts
- User-friendly command-line interface

## Technologies Used

- Python 3

## How to Run the Project

1. Install Python on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

```bash
python contact_book.py
```
