# To-Do List Application

## Project Description
This is a simple command-line To-Do List application developed using Python. The application helps users manage their daily tasks by allowing them to add, view, and remove tasks.

## Features
- Add new tasks
- View all tasks
- Remove completed tasks
- Simple and user-friendly interface
- Menu-driven program

## Technologies Used
- Python 3

## How to Run the Project

1. Install Python on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

```bash
python todo.py
