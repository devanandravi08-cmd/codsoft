# Rock-Paper-Scissors Game

## Project Description

This is a simple Rock-Paper-Scissors game developed using Python. The game allows a user to play against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is determined according to the game rules.

## Features

- User selects Rock, Paper, or Scissors
- Computer generates a random choice
- Determines the winner automatically
- Displays both user and computer choices
- Keeps track of scores
- Supports multiple rounds
- User-friendly command-line interface

## Technologies Used

- Python 3
- Random Module

## How to Run the Project

1. Install Python on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

```bash
python rock_paper_scissors.py
```

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- If both choices are the same, the game is a tie
